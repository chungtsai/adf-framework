# ADF v5.2 → v5.3 升級 SOP

## 適用範圍
已用 v5.1.0 或 v5.2.0 完成 `adf-project-install` 導入（有 `.adf/project.yaml` 與 `.adf/migration.json`）的專案。尚未導入的 v5.0 專案，請依 [v5.0 → v5.1 SOP](5.0-to-5.1.md) 的流程，並把文中的 tag 換成 v5.3.0。

v5.3 不改 Module 文件格式，也不撤銷任何核准狀態。不需要重跑 APPLY。

## 1. 升級前
1. 確認工作目錄乾淨，或先 commit 未提交變更。
2. 若曾手動修改已安裝的 ADF Skill，先把客製內容保存到專案外；重新安裝會覆蓋 Skill 檔案。

## 2. 更新

一行完成（自動沿用 Agent 與安裝模式、備份、比對、VERIFY，失敗自動還原）：

```bash
curl -fsSL https://raw.githubusercontent.com/chungtsai/adf-framework/main/scripts/update.sh | bash -s -- --version v5.3.0
```

Windows PowerShell：`& ([scriptblock]::Create((irm https://raw.githubusercontent.com/chungtsai/adf-framework/main/scripts/update.ps1))) -Version v5.3.0`。

或手動執行（Agent 與安裝模式沿用原本的選擇）：

```bash
npx skills add https://github.com/chungtsai/adf-framework/tree/v5.3.0 --list
npx skills add https://github.com/chungtsai/adf-framework/tree/v5.3.0 --skill '*' -a claude-code
```

檢查 `skills-lock.json`：33 支 Skill 的 `ref` 都是 `v5.3.0`，`computedHash` 已更新。

## 3. 驗收

```bash
node <skill-root>/scripts/project.mjs CHECK <project>
node <skill-root>/scripts/project.mjs VERIFY <project>
node <skill-root>/scripts/project.mjs STANDARDS <project>
```

- CHECK 沒有 blockers，VERIFY 回傳 `verified`。
- `STANDARDS` 列出 27 項起始規範與各自狀態（可安裝／已安裝／已有同名）。
- `.adf/project.yaml` 的 `tool_version` 維持 `5.1.0` 或 `5.2.0` 是正常的；5.3.0 接受此設定，不需要手動修改。

## 4. （可選）導入起始規範

```bash
curl -fsSL https://raw.githubusercontent.com/chungtsai/adf-framework/main/scripts/standards.sh | bash
```

建議項目預設全部安裝、輸入編號排除；選填項目輸入編號加入。之後要再加入其他規範，可在 Agent 中請 `adf-standard-authoring` 加入（見 README「專案起始規範」）。

## 常見問題
- **v5.2 時已用起始規範安裝過**：舊的編號已重新排序；重新執行只會新增尚未安裝的規範，已安裝與同 ID 的規範一律略過，不覆蓋。舊版範例檔（例如 `standards/development/security.md` 的 `# DEV-SEC-001`）不會被替換，需要新版內容時請以 `adf-standard-authoring` 修訂。
- **出現 `Missing/unsupported formal npx source`**：部分 Skill 仍是舊版，重新執行第 2 步並安裝全部 33 支。
- **出現 `Installed skill differs from npx lock`**：已安裝的 Skill 被手動修改過，先把客製內容移到 `standards/` 或專案外，再重新安裝。
- **需要回到 v5.2**：`update.sh --version v5.2.0`（或用 v5.2.0 tag 重新安裝）；v5.3 沒有改動專案資料，已寫入的 `standards/` 保留。
