所有情境都遵守的三條規則

檔案存在 ≠ Stage 完成

完成要看 Review 狀態與 Evidence。Artifact 剛產生時是 DRAFT，通過 Gate 才變成 APPROVED。

AI 不能自行核准

需要 Human Gate 的 Stage，只有 Human 明確確認後才能標記 APPROVED。退回時進入 Evidence-Guided Q&A 補充。

一個 Module 只有一個 Active Work Item

Module 是主要隔離邊界。導入與補驗證只驗證不改 Target，之後的修改另開 CHANGE。
