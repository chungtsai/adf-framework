# Label Schema

Recommended label dimensions:

## Work Type

- `adf::new`
- `adf::change`
- `adf::migration`

## Intent

- `intent::feature`
- `intent::bugfix`
- `intent::security`
- `intent::refactor`

## Workflow

- `status::todo`
- `status::analysis`
- `status::review`
- `status::development`
- `status::verification`

## Blocked Reason

- `blocked::requirement`
- `blocked::dependency`
- `blocked::environment`
- `blocked::human-review`

不要為 32 支 Skill 各建立 Label。
