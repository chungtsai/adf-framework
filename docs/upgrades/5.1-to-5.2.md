# ADF v5.1 → v5.2 升級 SOP

## 適用範圍
已用 v5.1.0 完成 `adf-project-install` 導入（有 `.adf/project.yaml` 與 `.adf/migration.json`）的專案。尚未導入 v5.1 的 v5.0 專案，請直接依 [v5.0 → v5.1 SOP](5.0-to-5.1.md) 的流程，並把文中的 tag 換成 v5.2.0。

v5.2 只調整 Skill 內容結構，不改 Module 文件格式，也不撤銷任何核准狀態。不需要重跑 APPLY。

## 1. 升級前
1. 確認工作目錄乾淨，或先 commit 未提交變更。
2. 若曾手動修改已安裝的 ADF Skill，先把客製內容保存到專案外；重新安裝會覆蓋 Skill 檔案。

## 2. 重新安裝
在專案根目錄執行，Agent 與安裝模式沿用原本的選擇：

```bash
npx skills add https://github.com/chungtsai/adf-framework/tree/v5.2.0 --list
npx skills add https://github.com/chungtsai/adf-framework/tree/v5.2.0 --skill '*' -a claude-code
```

檢查 `skills-lock.json`：33 支 Skill 的 `ref` 都是 `v5.2.0`，`computedHash` 已更新。

## 3. 驗收

```bash
node <skill-root>/scripts/project.mjs CHECK <project>
node <skill-root>/scripts/project.mjs VERIFY <project>
node <skill-root>/scripts/project.mjs resolve <project> core/invariants.md
```

- CHECK 沒有 blockers，VERIFY 回傳 `verified`。
- `resolve` 能找到 `core/invariants.md`、`core/runtime-compat.md`。
- `.adf/project.yaml` 的 `tool_version` 維持 `5.1.0` 是正常的；5.2.0 接受此設定，不需要手動修改。

## 常見問題
- **出現 `Missing/unsupported formal npx source`**：部分 Skill 仍是 v5.1.0，重新執行第 2 步並安裝全部 33 支。
- **出現 `Installed skill differs from npx lock`**：已安裝的 Skill 被手動修改過，先把客製內容移到 `standards/` 或專案外，再重新安裝。
- **需要回到 v5.1**：用 v5.1.0 tag 重新安裝即可；v5.2 沒有改動專案資料。
