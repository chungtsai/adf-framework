# ADF v5.1

新增 adf-project-install，33 支 Skill。統一專案層級 npx skills；官方範本與 Review 各自單一 owner。專案不保留官方或客製範本，客製必要資訊先歸入規範或需求文件。

保留 standards、modules、完成與核准狀態；舊格式 5.0 可使用，補做走 CHANGE。沒有 Issue Tracking 整合，也不建立 .adf/framework 或 install/base。

[移轉 SOP](../upgrades/5.0-to-5.1.md)。GitHub 分支／PR 是候選版；合併後須發佈 v5.1.0 tag 並實際驗收 npx 遠端安裝，才是可正式導入版本。

## 驗證界線
repository validate 與 Node 測試驗證結構、範本、盤點、寫入保護、相容性與回復。測試 fixture 模擬安裝後資料，不能代替 npx 實際下載驗收。首次發佈需保存 skills CLI 版本、Agent、OS、安裝模式、lockfile 欄位與資源解析結果。
