# Dialog usage
Dialogs are suitable for bounded detail viewing, create/edit, and confirmation flows. Define title/content/actions, save/cancel behavior, validation, unsaved-change handling, success refresh, and accessibility. Avoid dialogs for very large multi-step workflows or content requiring an independent URL.
