# ADF v5.5

## v5.5.0

新增 Work Item 驗收清單。Skill 由 33 支增為 34 支（新增 `adf-acceptance-checklist`）；Work Type、Intent 與 Q&A schema 不變；不需要重跑 APPLY，也不撤銷任何核准狀態。

## 變更

### 新 Skill：`adf-acceptance-checklist`
- 讀取本次 Work Item 的變更紀錄（`work_item.changes`）、影響範圍（manifest `impact`、`design.md`）、`behavior.preserve`／`approved_changes` 與已核准的 Requirement、Rule、Functional Scenario、Test、Traceability。
- 產生 `verification/acceptance-<work_item.id>.md`（範本 `template/verification/acceptance.md`）：本次說明、影響範圍、功能驗收（`AC-001` 起）、回歸確認（`AC-101` 起）、未解決項目與簽核欄。每個驗收項目附操作步驟、取自已核准 Artifact 的預期結果與對應 `TC-*` 的目前結果。
- 以 `base_ref` 到目前的版控差異比對 `changes`：差異中有但沒登記的 ID 標 `REVIEW_REQUIRED`，登記了但找不到差異的列入未解決項目。
- Human 填寫結果與簽核後再執行一次「回收」：通過 → `status.verification.acceptance: passed`；不通過 → `failed` 並把 `AC-*` 寫入 `blockers`；有條件通過 → 條件寫入 `blockers`，維持 `in_review` 由 Human 決定。AI 不代填結果、不代簽核。

### 本次變更紀錄（`core/invariants.md`）
- manifest `work_item` 新增 `base_ref`（建立 Work Item 時的 git commit，沒有版控填 `null`）與 `changes`（`added`／`modified`／`removed`）。
- 任何 Skill 在本次新增、修改或刪除 `REQ-*`、`LB-*`、`BR-*`、`VAL-*`、`Q-*`、`UI-*`、`FS-*`、`TC-*` 時，必須在同一次寫入登記；只改錯字或格式不登記。
- Compact Artifacts 新增 `verification/acceptance-<work_item.id>.md`；穩定識別碼加入 `AC-*`。
- manifest 範本新增 `status.verification.acceptance: pending`；`adf-feature-init` 建立 Work Item 時填 `base_ref` 並清空 `changes`，之前 Work Item 的驗收清單保留。

### Gate 與流程
- `adf-development-complete` 新增 Acceptance Gate：驗收清單 `passed` 才能結案；只有 Human 可標示 `not_applicable`。5.5.0 之前建立的 Work Item 由 Human 決定是否補做，未補做不得宣稱已完成驗收。
- `adf-develop` 新增 Acceptance Routing：Traceability 之後、Completion 之前執行驗收。

### 操作台網站
- 情境流程、QA 檢核、驗證方式、關鍵字（`AC-*`、`work_item.changes`、`acceptance`）、檔案說明與提示詞同步；新增「產生驗收清單」與「回收驗收結果」提示詞。

[升級 SOP](../upgrades/5.4-to-5.5.md)。發布前先打 `v5.5.0-beta.1` 驗收 npx 遠端安裝、更新與 Windows 腳本；通過後才合併並發布 v5.5.0 正式 tag。

## 相容性
- `resources.json` 的 `compatible_tool_versions` 加入 5.5.0（5.1.0～5.4.1 寫入的 `.adf/project.yaml` 可直接沿用）。
- 既有 manifest 沒有 `base_ref`、`changes`、`status.verification.acceptance` 時照常運作；需要驗收時由 `adf-acceptance-checklist` 依版控差異重建範圍並請 Human 確認。
- `skills-lock.json` 必須有 34 支 Skill 且 `ref` 一致；更新腳本會自動安裝新的 Skill。

## 驗證界線
`npm run validate`（34 支 Skill）與 `npm test` 通過。`adf-acceptance-checklist` 的實際效果（範圍重建、清單品質）尚未在真實專案試行；`v5.5.0-beta.1` 尚未發布。
