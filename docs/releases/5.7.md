# ADF v5.7

## v5.7.0

將 v5.6.0 試用的 Module 檢查工具（`module-check.mjs`）與格式規範正式納入強制流程，並訂定未達標文件的分級調整策略。Skill 總數維持 34 支，Work Type、Intent、manifest 範本與 Q&A schema 不變；已完成 Module 的核准狀態不撤銷，不需要重跑 APPLY。

## 變更

### 1. 共用規範正式升格：`core/module-format.md`
- 由原草案 `docs/proposals/module-format.md` 正式升格為官方單一來源資源 `core/module-format.md`（owner：`adf-project-install`，已登錄於 `resources.json`）。
- 納入強制檢核與 exit code（`0/1/2/3`）處置規則、A/B/C 三類未達標文件調整策略，以及既有 Module 的漸進轉換規則。
- `core/invariants.md` 補入程式化檢核定位與刪除保留列（`Status: REMOVED`）不變條件；`core/runtime-compat.md` 補入歷史 Module「碰到才轉換（Touch-to-Migrate）」與無 git 降級相容規則。

### 2. 分層強制流程（11 支相關 Skill）
- **結案強制預檢（`adf-development-complete`）**：結案前必須先執行 `module-check.mjs <module> --gate`；`exit 2` 停止、`exit 1`（`BLOCKED`）強制阻擋結案並依 A/B/C 問題分類退回對應 Skill、`exit 3`（`HUMAN_REQUIRED`）交由 Human 確認、`exit 0`（`READY`）進入最終 Human Completion Gate（工具結論不等於核准）。
- **追溯、驗收與診斷前哨**：`adf-traceability-check` 改以 `module-check --json` 作為斷鏈與覆蓋率基準並補入拆列轉換規則；`adf-acceptance-checklist` 先以工具核對 `R-04`/`R-05`；`adf-develop` 納入強制預檢與 Documentation Retrofit CHANGE 路由；`adf-ask` 優先以 `--gate --json` 進行唯讀診斷。
- **產出階段自檢**：`adf-requirement-analysis`、`adf-business-rule`、`adf-standards-applicability`、`adf-legacy-analysis`、`adf-test-generation`、`adf-result-comparison` 於寫檔後自檢格式與連結。

### 3. Artifact 範本標準化與範例列清理
- `requirements.md`、`rules.md`、`standards.md` 補上標準表格標題列；`traceability.md` 新增 `Evidence` 欄與「每列單一 Source 與 Test」規則；`legacy-behavior.md` 行為清單新增選填 `Status` 欄。
- 移除 `test-cases.md`、`functional-scenarios.md`、`legacy-behavior.md`、`comparison.md`、`acceptance.md` 範本中的範例列（範例移至各 `SKILL.md`），避免新建 Module 殘留範例列觸發 `R-01` 斷鏈錯誤。

### 4. `module-check.mjs` 與測試補強
- `R-07` 狀態矛盾檢查擴展涵蓋 `status.analysis`（`requirements.md`、`rules.md`、`legacy-behavior.md`）與 `status.verification.test_generation`。
- `tests/module-check.test.mjs` 新增新版無範例列官方範本零誤報測試與 R-07 擴展測試。

### 5. 操作台網站與情境流程動畫
- 操作台（`index.html`）移除「試用」標籤，同步版本至 v5.7.0，補齊強制預檢與 A/B/C 文件調整指引。
- 情境流程動畫（`flows.html`）於既有開發／移轉／修改情境的 `Completion Gate` 前加入強制預檢步驟，並新增第 11 個情境「結案預檢與文件健檢」，以互動分支演示 `BLOCKED`（A/B/C 類問題調整）、`HUMAN_REQUIRED` 與 `READY`。

[升級 SOP](../upgrades/5.6-to-5.7.md)。

## 相容性
- `resources.json` 的 `compatible_tool_versions` 加入 `5.7.0`（5.1.0～5.6.0 寫入的 `.adf/project.yaml` 可直接沿用）。
- 已完成 Module 不撤銷核准，採「碰到才轉換（Touch-to-Migrate）」。
- `skills-lock.json` 必須有 34 支 Skill 且 `ref` 一致。
