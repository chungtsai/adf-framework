# 移轉顯示一致（與舊系統相同即可）

## 目的
移轉專案的顯示驗收以「與舊系統一致」為準，不另行重新設計訊息與文字。避免移轉過程同時改寫文字，造成使用者困擾與比對困難。

## 規則
- **MIG-DISP-001-R1 文字一致**：以下內容與 Legacy 相同即可通過：訊息文字（成功、錯誤、警告、確認、查無資料）、欄位標籤、按鈕名稱、表頭、下拉選項文字、頁籤與標題。
- **MIG-DISP-001-R2 資料呈現一致**：代碼顯示方式（只顯示代碼、只顯示名稱或「代碼-名稱」）、數字格式（千分位、小數位數、負數表示）、空值顯示、預設排序與每頁筆數，與 Legacy 相同。
- **MIG-DISP-001-R3 不強制共用訊息**：移轉 Module 不需為了 `DEV-MSG-001` 改寫訊息；若同時導入共用訊息目錄，訊息內容仍以 Legacy 文字為準。
- **MIG-DISP-001-R4 不自行修正**：Legacy 文字有錯字或明顯錯誤時，不在移轉中直接修正；標 `REVIEW_REQUIRED`，經 Human 核准後列為 `APPROVED_BEHAVIOR_CHANGE`。

## 允許的差異（不算缺陷）
- 版面配置、字型、顏色、元件樣式、響應式排版。
- 頁面改為 Dialog 等導覽方式（需 `MIG-UI-001`）。
- 日期由民國年改為西元年（需 `MIG-DATE-001`）。

## Normalization（結果比對時）
- 文字比對前去除前後空白與 HTML 標記；其他任何文字差異都視為差異，依 `adf-result-comparison` 分類。

## 驗證方式
- 每個主要 `FS-*` 至少比對：必填錯誤訊息、格式錯誤訊息、成功訊息、查無資料訊息、確認對話框文字。
- 清單畫面比對欄位標籤、表頭順序、代碼顯示方式與預設排序。

## 相關規範
