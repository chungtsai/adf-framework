# Issue Schema

External Issue 建議只保留管理資訊，不複製完整 ADF Spec。

Required summary:

- Title
- Module
- ADF Work Item ID
- Work Type
- Intent
- Background
- Requirement Summary
- Initial Impact
  - Frontend
  - Backend
  - Database
  - Security
- ADF Artifact Location
- Definition of Done
- Tracking metadata

完整 BR/Q/VAL/UI、Design、Test、Traceability 必須留在 ADF Artifacts。
