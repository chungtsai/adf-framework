# GitHub-only Distribution

ADF does not need to be published as an npm package.

## Skills
Install directly from the GitHub repository with the skills installer.

## Project assets
Clone the repository and run `node scripts/init.js <target-project>`.

## Private repositories
Use your organization's normal Git/GitHub authentication and access controls. Keep company-specific standards in a private repository when appropriate.

## Future npm release
A future npm wrapper can be added without changing the `skills/`, `framework/`, or module model.
