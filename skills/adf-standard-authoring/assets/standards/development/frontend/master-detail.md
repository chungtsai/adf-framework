# Master-detail workspace
For simple master/detail viewing or maintenance, prefer keeping the user in the same work area rather than navigating to a separate detail page. Use an approved dialog/drawer pattern unless the detail needs an independent URL, complex multi-step workflow, or substantial sub-functions.
