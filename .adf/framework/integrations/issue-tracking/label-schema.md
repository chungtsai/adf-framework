# Label Schema

Recommended dimensions:

## Work Type

- adf::new
- adf::change
- adf::migration

## Intent

- intent::feature
- intent::bugfix
- intent::security
- intent::refactor

## Workflow

- status::todo
- status::analysis
- status::review
- status::development
- status::verification

## Blocked Reason

- blocked::requirement
- blocked::dependency
- blocked::environment
- blocked::human-review

Do not create a label for every ADF stage or skill.
